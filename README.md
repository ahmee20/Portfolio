# Ahmad Mehmood - AI Engineer Portfolio (Loft OS)

Interactive, pixel-art retro OS "Loft" portfolio for Ahmad Mehmood (AI Engineer & Machine Learning Specialist).

## 🚀 Features

- **Loft OS Theme**: Pixel-art walk-around loft house with 8 interactive rooms:
  - **Living Room**: About & Bio
  - **Workshop**: Featured Projects & Case Studies
  - **Office**: Professional Experience
  - **Gym**: Technical Skills & Stack
  - **Study**: Education & Certifications
  - **Trophy Wall**: Achievements & Milestones
  - **Garage**: Resumes (AI Engineer & ML Specialist)
  - **Rooftop**: Contact & Social Links
- **Interactive Windows**: Draggable / Minimizable / Maximizable OS windows.
- **Retro Music Player**: Built-in soundtrack player with custom tracks and controls.
- **Pixel-Guide**: Contextual pixel companion guide.
- **Responsive Layout**: Designed for seamless desktop and mobile experiences.

## 🛠️ Tech Stack

- React.js / Modern JavaScript
- Tailwind CSS & Radix / Lucide Icons
- HTML5 Audio & Canvas
